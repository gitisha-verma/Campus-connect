# 🎓 Campus Connect

A college campus platform designed for students and administrators.

## 📌 About the Project

Campus Connect is a web-based platform developed to provide a
centralized digital space for students and college administrators.

The project aims to make campus-related interactions and
information management more convenient.

## 🛠️ Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Python, Flask
- Version Control: Git & GitHub

## 👩‍💻 Project Status

Development completed. Deployment is in progress.
